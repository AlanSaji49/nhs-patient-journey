# NHS Patient Journey

An interactive teaching tool showing how adult patients enter, move through and leave an NHS acute hospital.

It is a single, self-contained web page (`index.html`) with no build step, no tracking and no data collection.

## What it covers

The page has four tabs:

1. **The journey**: a clickable map of five stages
   - Stage 1: Inflows (unplanned and planned routes into hospital)
   - Stage 2: Front door (ED, SDEC, admission lounge, direct specialist units)
   - Stage 3: Assessment (AMU and SAU)
   - Stage 4: Inpatient care (treatment escalation, levels of care, procedural areas)
   - Stage 5: Discharge

   It also includes Chart B (discharge from the wards) and Chart C (short-form discharge from ED, SDEC, AMU/SAU and day case).
2. **Case 1**: a worked example of a major trauma patient
3. **Case 2**: a worked example of an older patient with a chest infection and a delayed discharge
4. **Abbreviations**: a searchable list of the terms used

## Scope

Adult acute and elective pathways only. Paediatric, maternity and mental health pathways are excluded.

## Disclaimer

- This is an educational resource for non-clinical learners. It is not clinical guidance and must not be used to make decisions about patient care.
- Pathways are simplified. Local practice, unit names and processes vary between NHS trusts.
- The patients in the worked cases are fictional. Any resemblance to real people is coincidental.

## Viewing

Open `index.html` in any modern web browser, on a computer or phone. It works offline, though the custom fonts need an internet connection (standard fonts are used otherwise).

## Updating

Replace `index.html` with the new version. If the repository is connected to a hosting service such as Vercel, the live page updates automatically.
